# 📱 Glide App

## Use Case

Built a simple no-code mobile application to organize and browse volcano information using an Excel dataset.

## What I Did

- Created an Excel dataset with volcano information
- Uploaded the dataset to Glide
- Converted the data into a mobile application
- Created a card-based collection
- Mapped Name, Description and Photo fields
- Added search functionality
- Configured basic navigation and a User Profile section

## Workflow

Excel Dataset → Glide → Data Collection → Card Layout → Mobile App

## Key Learning

Learned how a no-code platform can transform structured spreadsheet data into a functional, searchable mobile application without traditional coding.

## Platform

**Glide Free Version** — Application developed and tested using the free version; publishing and broader deployment can be enabled through a paid Glide plan.
